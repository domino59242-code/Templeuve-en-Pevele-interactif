Comment utiliser cette page

  1. Ouvre admin.html via un petit serveur local (voir le message affiché en haut si tu vois une erreur de chargement — les fichiers JSON ne se chargent pas en ouvrant simplement le fichier avec un double-clic).
  2. Ajoute, modifie ou supprime des lieux et/ou des catégories avec les formulaires.
  3. Clique sur Télécharger lieux.json et/ou Télécharger categories.json : le fichier à jour est téléchargé dans ton dossier de téléchargements.
  4. Remplace les fichiers correspondants dans data/lieux.json et data/categories.json de ton projet.
  5. Si ton site est hébergé (GitHub Pages par exemple), envoie les modifications avec git add, git commit puis git push.

Cette page ne modifie jamais tes fichiers automatiquement : c'est volontaire, un site statique ne peut pas écrire sur le serveur depuis le navigateur. Le téléchargement + remplacement manuel est la façon la plus simple de rester sans base de données.
